IDOL Certified Payroll Extractor

Reads Illinois Department of Labor (IDOL) Certified Transcript of Payroll (CTP) PDFs

Reading PDFs

    Results

    Applies to the counts, wage panel, table, and CSV downloads. JSON and complaint letters always use all rows.

    Payroll data

    One row per employee per payroll report. Key columns come first, and supporting details follow after the divider. The Employee column stays in place when you scroll sideways. The two CSV buttons at the top of the page export either the whole classification scope or only the rows that match the filters below.

    Complaint letters

    Plain text for prevailing wage complaints, built from the extracted data. The tool writes one separate letter for each contractor that has findings. Check every figure against the source PDFs, edit the text if you need to, and paste each letter into its complaint narrative field.

    The prevailing rates in this tool are Cook County Laborer rates. Confirm that the workers named in each finding are laborers on a Cook County project.

      Changing an option above rewrites the letters and removes any edits you made. The tool asks you to confirm first if you have edited a letter.
